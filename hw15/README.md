Требования к реализации:

реализовать обработку доменной сущности через каналы Spring Integration;
уметь осуществлять "интеграцию" частей приложения с помощью EIP.

Описание/Пошаговая инструкция выполнения домашнего задания:

0. Выберите другую доменную область и сущности. Пример: превращение гусеницы в бабочку.

1. Опишите/сконфигурируйте процесс (IntegrationFlow) с помощью инструментария предоставляемого Spring Integration.

2. Желательно использование MessagingGateway и subfolw (при необходимости).

3. Можно взять модель с бабочкой: 
   EGG - Яйцо
   LARVA - Личинка
   PUPA - Куколка
   ADULT - Взрослая бабочка
